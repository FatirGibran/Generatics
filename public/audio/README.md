# Audio Files - Debate Generatics 2026

Simpan file audio instrumental di folder ini jika Anda memiliki file MP3 aslinya:
- **Nama file:** `every-summertime.mp3` (atau `niki-every-summertime.mp3`)
- **Lokasi:** `public/audio/every-summertime.mp3`

Sistem web player Generatics akan otomatis memutar file MP3 ini secara *looping* jika file terdeteksi. Jika file belum dimasukkan, sistem secara otomatis memutar aransemen instrumental sintetis *Every Summertime* (NIKI) berbasis Web Audio API agar musik tetap terdengar langsung tanpa jeda.
