# Pintasan Papan Ketik (Keyboard Shortcuts)

## Navigasi Panitia
- Tombol `/`: Memfokuskan kursor langsung ke bilah pencarian peserta atau mosi di dashboard admin.
- Tombol `Escape`: Menutup modal yang sedang terbuka tanpa menyimpan perubahan.
- Tombol `Tab` & `Shift+Tab`: Navigasi fokus aksesibilitas penuh pada elemen form dan tombol aksi.
